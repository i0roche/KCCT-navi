# 高専マップナビゲーション

高専構内の建物・部屋間の経路案内を行うデスクトップアプリケーションです。

> 本アプリケーションは、高専の実験課題として制作されました。

## 概要

学内の学生向けに、キャンパス内の目的地までの最短経路を案内します。建物名や部屋名で検索し、フロアをまたいだナビゲーションが可能です。

## 機能

### マップ表示
- キャンパス全体のSVGマップを表示
- マウスドラッグで移動、ホイールでズーム
- 階数切り替えボタン（右下）で各フロアを閲覧

### 経路検索
- 出発地・目的地を入力して最短経路を検索
- 建物名、部屋名、タグでの検索に対応
- 候補のサジェスト表示

### お気に入り
- よく使う部屋をお気に入りに登録
- お気に入りから出発地・目的地に設定

### 建物メニュー
- メニューバーから建物・階を選択して表示

## ビルド・実行

### 必要環境
- Windows 10/11
- .NET 8 SDK
- Visual Studio 2022 (推奨)

### ビルド
```bash
dotnet build
```

### 実行
```bash
dotnet run
```

## 使い方

### 経路検索
1. 左側パネルの「出発地」に出発場所を入力
2. 「目的地」に行き先を入力
3. 「検索」ボタンをクリック
4. マップ上に経路が表示されます

### 階の移動
- 右下の **▲ / ▼ ボタン** で階を切り替え
- または、メニューバーから建物・階を選択

### お気に入り登録
1. マップ上の部屋ノード（青い点）をクリック
2. 情報パネルで「お気に入り」ボタンをクリック
