高専構内の建物・部屋間の経路案内を行うデスクトップアプリケーションです。

> 本アプリケーションは、高専の実験課題として制作されました。

## 概要

学内の学生向けに、キャンパス内の目的地までの最短経路を案内します。建物名や部屋名で検索し、フロアをまたいだナビゲーションが可能です。
文化祭などで普通のモニター・マウス・キーボードで展示するための **展示モード** があります。

## 機能

### マップ表示
- キャンパス全体のSVGマップを表示
- マウスドラッグで移動、ホイールでズーム（マウス位置を中心に拡大縮小）
- タッチパッド（精密タッチパッド）の二本指で、スマートフォンの地図のように 移動・拡大縮小・回転 を同時にできる（拡大・回転の中心はマウスカーソルの位置）
  - 回転しても部屋名・建物名は読める向きのまま。`Home` で向きと倍率を元に戻す。キーボードは `Q` / `E` で 15° ずつ回転
  - 精密タッチパッドでない場合も、ピンチ（Ctrl+ホイール）で拡大縮小はできる（回転はできない）
- 慣性スクロール: ドラッグして離すと、地図が少し滑ってから止まる
- キーボード: 矢印キー / WASD で移動、`+` `-` でズーム、`1`〜`9` で階の切り替え、`Home` で全体表示
- 全体表示は、校内の建物・体育館までを余白少なく見せる。このとき部屋の点は出さず（お気に入りだけ表示）、棟の名前を読みやすく出す。棟をクリックするとその建物へ拡大し、拡大すると部屋の点と名前が出る
- タッチ操作（ピンチなど）にも対応
- 階数切り替えボタン（右下）で各フロアを閲覧
- 部屋ノードの色分け表示
  - 青（ブルー）：一般の部屋
  - 緑（グリーン）：トイレ
  - 紫（バイオレット）：階段
  - 黄（アンバー）：お気に入り登録済み
- 部屋をクリックすると吹き出しが出て、「ここから出発」「ここへ行く」「お気に入り」を選べる（右クリックでも出発地・目的地に設定できる）
- ズームレベルに応じたラベル表示
  - 1.2倍以上：すべての部屋名を表示
  - 0.6～1.2倍：お気に入りの部屋のみ表示
  - 0.6倍未満：ラベル非表示（ノードのみ）

### 経路検索
- 出発地・目的地を入力して最短経路を検索（A*アルゴリズム）
- 建物名、部屋名、タグでの検索に対応（空白区切りで AND 検索。例: `電子 技術職員室`）
- リアルタイムサジェスト表示（同名の部屋は「名前 (建物,階)」で区別）
- 階をまたぐ経路の表示（階段マーカー付き）
  - エメラルドグリーン（UP）：上の階へ
  - アンバー（DOWN）：下の階へ
  - インディゴ（LINK）：階段の接続点
- START/GOALマーカー表示、経路は出発地から伸びるアニメーションで表示

### お気に入り
- よく使う部屋をお気に入りに登録
- お気に入り一覧から出発地・目的地に設定
- お気に入りは黄色のノードで表示
- お気に入りデータの永続化（`%APPDATA%\KosenCampusNavi\favorite.json`）

### 雨の日モード
- 経路の入力欄の「雨の日 (屋外を避ける)」にチェックすると、屋外を通る道を遠回りしてでも避けて案内する
- 屋外しか道が無い場所（体育館など）へは屋外を通り、その旨を表示する
- 屋外かどうかは通路ごとに `src/team1/Data/outdoor_edges.txt`（屋外の通路の両端のノード ID）に持つ。KCCT-SiteMap の `IsOutdoor` から作ったので、屋根のある渡り廊下（体育館への道など）は屋外にならず、雨でも濡れずに行ける

### 行き先の選び方（マウス・キーボード）
- 画面は6班の作品に合わせた配置:
  - 上のツールバー: [マップ] [一覧] の切り替え、検索（入力すると候補が出る）、お気に入り、階の ▼▲、拡大縮小（− 100% ＋）
  - その下の経路の入力欄（KCCT-SiteMap の画面に合わせた配置）: [出発地] ⇄ [目的地] [表示] [クリア]、☐雨の日、☐階段を避ける、[近くの施設 ▼]
  - 経路が見つかると、右に「行き方」の手順が出る。下のステータスバーに出発地・案内を表示する
- 上のメニューバーの「建物」から建物 → 階を選ぶと、その階の建物へ地図が移動する
- 「検索」（`Ctrl+F` または `/`）で部屋名を入力して検索（空白区切りで AND 検索）
- 「表示 → 部屋一覧」（`L`）で、種別・建物・名前で絞り込んだ部屋の一覧を表示。ダブルクリックで地図上の場所を開く（`M` で地図に戻る）
- 階段・エレベーター・トイレは建物の一覧には出さず、「一番近い○○」で選ぶ
- `Esc` で経路と選択を消して最初の画面に戻る
- ヘルプ（`F1` またはメニューの「ヘルプ」）は別ウィンドウで開き、地図を見ながら読める。「使い方」「キー」「情報」の3つの短い表に分けてある（展示モードでは出さない）

### 無人運用（展示）の設定
操作画面は通常起動と同じ（ツールバー・経路の入力欄・メニューバー）。`--kiosk` または `kiosk.json` の `"Kiosk": true` で次を加える。
- 全画面・枠なし表示
- 文字入力なしでも行き先を選べる: 「建物 → 階 → 部屋」または「一番近いトイレ / エレベーター」
- 「一番近い」は直線距離ではなく、実際に歩く経路が最短のものを選ぶ
- 行き方を手順で表示（例: 「階段で 3F へ上がる」）
- 展示場所を「現在地」として表示し、出発地の初期値にする
- 一定時間（既定 90 秒）操作がないと最初の画面に戻る
- お気に入りは無効（来場者同士で共有されないように）
- 予期しないエラーが起きても初期画面に戻って動作を続ける（記録: `%LOCALAPPDATA%\KosenCampusNavi\error.log`）

## ビルド・実行

### 必要環境
- Windows 10/11
- .NET 8 SDK
- Visual Studio 2022 (推奨)

### ビルド
```bash
dotnet build src/team1.sln
```

### 実行
```bash
dotnet run --project src/team1/team1.csproj
```

### 展示モードで実行
```bash
dotnet run --project src/team1/team1.csproj -- --kiosk
```

### テスト
```bash
dotnet test tests/team1.Core.Tests
```

### 地図データの検証
SVG のノードと JSON の場所が対応しているか、すべての場所に経路が引けるかを確認します（CI でも実行）。
```bash
python scripts/validate_data.py              # 整合性のみ
python scripts/validate_data.py --optimality # A* が最短経路を返すかも確認
```
命名規則は [src/team1/Data/NAMING_CONVENTIONS.md](src/team1/Data/NAMING_CONVENTIONS.md) を参照してください。

## 使い方

### 経路検索
1. 上の欄に出発地と目的地を入力する（入力すると候補が出る）。または地図の部屋をクリックして、吹き出しの「ここから出発」「ここへ行く」を選ぶ
2. 「表示」を押す（出発地を空にすると、展示場所の「現在地」から探す）
3. マップ上に経路が、右に行き方の手順が表示されます。経路が見えるよう自動で拡大し、階のボタンで階を切り替えると、その階の経路へ拡大します。「雨の日」「階段を避ける」を切り替えると、その場で経路を引き直す

### 階の移動
- 右下の **▲ / ▼ ボタン** で階を切り替え
- または、ツールバーの ▼▲ や、メニューの「建物」で建物・階を選択

### お気に入り登録
1. マップ上の部屋ノード（色付きの点）をクリック
2. 吹き出しが開くので「お気に入りに追加」をクリック（ツールバーの「★ お気に入り」から一覧を開ける）
3. お気に入りに登録された部屋は黄色で表示されます
4. 吹き出しの「お気に入りから外す」で登録解除も可能

## 展示の準備

1. Release ビルドを展示用 PC に置く
   ```bash
   dotnet publish src/team1/team1.csproj -c Release -r win-x64 --self-contained
   ```
2. 出力先の `kiosk.json` を編集する
   - `"Kiosk": true` にする（または起動引数 `--kiosk`）
   - `"CurrentLocationId"` に展示場所の部屋 ID（`Data/*.json` の `"Id"`）を書く
   - 無操作で戻るまでの秒数 `"IdleResetSeconds"`、終了キー `"ExitKey"` を必要なら変える
   - 大きな画面では `"UiScale"` で画面全体の拡大率（0.75〜3）を決める。`null` のままなら、展示モードのときだけ画面の高さから自動で決める（900px で 1 倍、フルHD で 1.2 倍、4K で 2.4 倍。Windows の拡大を引いた後の高さ）。文字・ボタン・地図のラベルがそろって大きくなる
3. 展示用の PC で起動し、クリック・ホイール・矢印キー・「一番近いトイレ」・雨の日モードなどを一通り試す
4. 展示モードの終了は **Ctrl + Shift + Q**（`ExitKey` で変更可）
5. 自動起動させる場合は、Windows の「スタートアップ」フォルダーに `team1.exe --kiosk` のショートカットを置く

## 謝辞

同じ実験の他班の作品から機能のアイデアを得て、本班で実装しました。両班の作者から、参考にすることの許可をいただいています。
**他班のコード・画像はそのままは取り込んでいません**（本班で書き直したものです）。地図データでは、KCCT 班の部屋・通路の座標だけを使って、`map.svg` に無かった部屋のノードと通路を追加しました（下記）。

- **KCCT-SiteMap 班** ([canta-9142/KCCT-SiteMap](https://github.com/canta-9142/KCCT-SiteMap))
  - 「一番近いトイレ」などカテゴリでの目的地指定
  - 地図データの整合性を保つ考え方
  - 部屋・通路の座標 (`GraphData.json`, `FacilityData.cs`)。体育館・プール・弓道場・機械工学科実験実習棟などのノードと通路を、座標を team1 の地図に合わせて追加した (`scripts/add_missing_nodes.py`)
  - 屋外かどうかを通路に持たせて、雨の日に屋外を避ける経路（通路ごとの `IsOutdoor` を、座標を合わせて team1 の通路に移した。`scripts/mark_outdoor_edges.py`）
- **6班 (Group6SchoolMap)** ([2025D3T02/Group6SchoolMap](https://github.com/2025D3T02/Group6SchoolMap), MIT / Apache-2.0)
  - タッチパッド/タッチ操作（ピンチ・慣性）、キーボードでの地図操作（矢印・WASD）。タッチパッドの指の位置を Raw Input (HID) から読む方法（`TouchpadReader`）は、6班の TouchpadHelper を参考に、必要な部分だけ P/Invoke で書き直した
  - 種別で絞り込める部屋一覧画面
  - 全体図から建物を選んで中へ入る操作
  - DI と Usecase/Repository による層の分け方、データを変換スクリプトで検証する仕組み
