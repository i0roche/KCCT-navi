高専構内の建物・部屋間の経路案内を行うデスクトップアプリケーションです。

> 本アプリケーションは、高専の実験課題として制作されました。

## 概要

学内の学生向けに、キャンパス内の目的地までの最短経路を案内します。建物名や部屋名で検索し、フロアをまたいだナビゲーションが可能です。

## 機能

### マップ表示
- キャンパス全体のSVGマップを表示
- マウスドラッグで移動、ホイールでズーム（マウス位置を中心に拡大縮小）
- 階数切り替えボタン（右下）で各フロアを閲覧
- 部屋ノードの色分け表示
  - 青（ブルー）：一般の部屋
  - 緑（グリーン）：トイレ
  - 紫（バイオレット）：階段
  - 黄（アンバー）：お気に入り登録済み
- ノード右クリックで出発地、目的地に設定
- ズームレベルに応じたラベル表示
  - 1.2倍以上：すべての部屋名を表示
  - 0.6～1.2倍：お気に入りの部屋のみ表示
  - 0.6倍未満：ラベル非表示（ノードのみ）

### 経路検索
- 出発地・目的地を入力して最短経路を検索（A*アルゴリズム）
- 建物名、部屋名、タグでの検索に対応
- リアルタイムサジェスト表示
- 階をまたぐ経路の表示（階段マーカー付き）
  - エメラルドグリーン（UP）：上の階へ
  - アンバー（DOWN）：下の階へ
  - インディゴ（LINK）：階段の接続点
- START/GOALマーカー表示

### お気に入り
- よく使う部屋をお気に入りに登録
- お気に入り一覧から出発地・目的地に設定
- お気に入りは黄色のノードで表示
- お気に入りデータの永続化

### 建物メニュー
- メニューバーから建物・階を選択して表示
- 建物別の階層構造で整理
- 階を選択すると自動的にマップが切り替わる

## ビルド・実行

### 必要環境
- Windows 10/11
- .NET 8 SDK
- Visual Studio 2022 (推奨)

### ビルド
```bash
dotnet build src/team1.sln
```

### 実行
```bash
dotnet run --project src/team1.csproj
```

## 使い方

### 経路検索
1. 左側パネルの「出発地」に出発場所を入力(または右クリックメニューから選択)
2. 「目的地」に行き先を入力(または右クリックメニューから選択)
3. 「検索」ボタンをクリック
4. マップ上に経路が表示されます

### 階の移動
- 右下の **▲ / ▼ ボタン** で階を切り替え
- または、メニューバーから建物・階を選択

### お気に入り登録
1. マップ上の部屋ノード（色付きの点）をクリック
2. 右側の情報パネルが開くので「お気に入りに追加」ボタンをクリック
3. お気に入りに登録された部屋は黄色で表示されます
4. お気に入りパネルから登録解除も可能
